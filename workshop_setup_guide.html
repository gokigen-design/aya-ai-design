STEP 1

Node.js のインストール確認

Claude Code を動かすために必要な「土台」です

1

「ターミナル」アプリを開く
Spotlight検索（Command + Space）で「ターミナル」と入力

2

下記を打ち込んでEnterを押す

ターミナル
% node --version
3

結果を確認する

v18.19.0 ← このように数字が出ればOK
zsh: command not found: node ← 出た場合は下記へ

「command not found」が出た場合

Node.js が入っていません。nodejs.org を開いて、「LTS」と書かれた緑のボタンからダウンロード・インストールしてください。
インストール後、ターミナルを一度閉じて開き直してから、もう一度 node --version を試してください。

Windowsの方：まずセキュリティ設定を変更します

Windowsでは最初にこの設定が必要です（初回のみ）。

1

Windowsキーを押して「PowerShell」と検索
「Windows PowerShell」を右クリック →「管理者として実行」をクリック

2

下記をコピペしてEnter

PowerShell（管理者）
PS > Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

確認が出たら 「Y」を打ってEnter

3

次に、通常のターミナル（コマンドプロンプト）を開いて確認

コマンドプロンプト
C:\> node --version
v18.19.0 ← 数字が出ればOK

数字が出なかった場合

nodejs.org から「LTS」版をダウンロード・インストールしてください。

STEP 1 完了チェック

  • ターミナルに「v18.○○」などのバージョン番号が表示された

STEP 2

Claude Code のインストール

コマンド1行で完了します

1

ターミナルに下記を打ち込んでEnter
（インストールに数分かかります。そのまま待ってください）

ターミナル / コマンドプロンプト
% npm install -g @anthropic-ai/claude-code
...（しばらく待つ）
added 247 packages in 45s ← このような表示で完了
2

途中で確認が出た場合は 「Y」または「Yes」を選んでEnter で進めてください。

確認画面が出たら

「このフォルダを信頼しますか？」「続けますか？」などの確認はすべて 「Yes」「Y」「Enter」 で進めてOKです。

STEP 2 完了チェック

  • 「added ○○ packages」と表示された
  • エラー（赤い文字）が出ていない
3

STEP 3

Claude Code の起動とログイン

初回はClaude.aiアカウントとの連携が必要です

1

ターミナルに打ち込んでEnter

% claude
2

ログイン方法の選択画面が出ます。1番（Claude account with subscription） がすでに選ばれているので、そのまま Enter を押す。

Select login method:

> 1. Claude account with subscription · Pro, Max, Team, or Enterprise
   2. Anthropic Console account · API usage billing
   3. 3rd-party platform

Enter to select
3

ブラウザが自動で開いてClaude.aiのログイン画面が出ます。
お持ちのClaude.aiアカウントでログインして「承認する」を押す。

ブラウザが開かなかった場合（Windowsに多い）

ターミナルに長いURLが表示されます。
1. キーボードの 「c」 を押す（URLが自動コピーされます）
2. ChromeやEdgeを開き、アドレスバーに貼り付けてEnter
3. ログインして「承認する」を押す
4. ブラウザに表示されたコードをコピー
5. ターミナルに戻り、「Paste code here if prompted >」の横に 右クリックで貼り付けて Enter

「OAuth error: status code 400」が出た場合

認証コードの時間切れです。「Press Enter to retry」と出るのでEnterを押して最初からやり直してください。今度は素早く進めるとうまくいきます。

4

ログイン成功すると、下のような画面が出ます。
「このフォルダを信頼しますか？」と聞かれたら Enter を押して進む。

Login successful. Press Enter to continue...

Accessing workspace:
/Users/yourname

> 1. Yes, I trust this folder
   2. No, exit

Enter to confirm

虫マーク（Claude Code）が表示されたら起動成功です。

STEP 3 完了チェック

  • 虫マークのアイコンが画面に表示された
  • 「Welcome back ○○！」または「> Try...」という入力欄が出た
4

STEP 4

Superpowers プラグインの導入

Claude Codeをパワーアップする必須プラグインです

1

まずターミナルに下記を打ってEnter（Claude Codeを起動する）

ターミナル
% claude
...
> （虫マークが出て、この入力欄が出たらOK）

STEP 3が終わっていれば

すでに虫マークの画面が出ている場合は、この手順は不要です。そのまま次へ進んでください。

2

Claude Codeの入力欄（> の横）に下記を貼り付けてEnter

Claude Code 入力欄
> /plugin install superpowers@claude-plugins-official
3

インストール先を選ぶ画面が出ます。
「Install for you (user scope)」 がすでに選ばれているので、そのまま Enter を押す。

4

「Installed superpowers」と出たら、続けて下記を入力してEnter

> /reload-plugins
Reloaded: 1 plugin ... ← この表示で完了

STEP 4 完了チェック

  • 「Installed superpowers」と表示された
  • 「/reload-plugins」後に「Reloaded: 1 plugin」と表示された
5

STEP 5

UI/UX Pro Max スキルの導入

デザイン・配色・レイアウトに強くなるスキルです

大事なポイント

このスキルはターミナルのClaude Code（虫マークの画面）から導入します。
ブラウザで開くClaude.aiのチャット欄ではありません。

1

Claude Codeの入力欄に下記をそのまま貼り付けてEnter

Claude Code 入力欄
> https://github.com/nextlevelbuilder/ui-ux-pro-max-skill.git
このスキルを導入してください
2

Claudeが確認してきます。入力欄に下記を打ってEnter

実行してよろしいですか？

> 実行しても良い
3

「インストール完了しました」または「UI/UX Pro Max スキルが…にインストールされました」と出たら完了。

STEP 5 完了チェック

  • 「インストール完了しました」と表示された
6

STEP 6

Chrome拡張「Claude in Chrome」の導入

ブラウザからClaudeを使えるようになります

1

Google Chromeを開いて、Chromeウェブストアで「Claude in Chrome」または「Claude for Chrome」を検索する

2

「Chromeに追加」ボタンをクリックする

3

確認ダイアログが出たら「拡張機能を追加」をクリック

4

右上のパズルピースアイコンから「Claude in Chrome」をピン留めすると使いやすい

STEP 6 完了チェック

  • Chromeのツールバーにアイコンが追加された

TROUBLE

よくあるトラブルと解決方法

詰まったときはここを確認してください

「zsh: command not found: claude」が出た

Claude Code がインストールされていません。
STEP 2 に戻って npm install -g @anthropic-ai/claude-code を実行してください。

Windowsで赤い文字のエラー（スクリプトの実行が無効…）が出た

STEP 1 の「Windowsの方：管理者PowerShellでの設定」に戻ってください。
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser を実行して「Y」でEnterです。

ログイン中に「OAuth error: status code 400」が出た

認証コードの時間切れです。「Press Enter to retry」と出たらEnterを押して最初からやり直してください。今度は素早く進めることがコツです。

「外部のGitHubリポジトリから導入できません」と言われた

ブラウザのClaude.aiにURLを貼ってしまっています。
ターミナルでclaudeコマンドを起動して（STEP 3）、そちらの入力欄に貼ってください。

「リマインダーへのアクセスを許可しますか？」が出た（Mac）

「許可しない」で大丈夫です。どちらを選んでもClaude Codeは正常に使えます。

途中で確認画面が何度も出て困った

「Yes, I trust this folder」「Y」「承認する」「実行しても良い」——どの確認もすべて 「はい」「Yes」「Enter」 で進めて大丈夫です。

それでも解決しない場合

エラー画面のスクリーンショットを撮って、LINEまたはSlackでお送りください。
