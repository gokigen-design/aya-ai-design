& me LP Lab

プロンプトの違いで LP の仕上がりはどう変わる？4ステップ検証レポート

あや ゆみ ちゃかな

検証の目的

同じサービス「& me（ファッションコミュニティ）」のLPを、プロンプトの詳しさを段階的に変えながら4回作成。
初心者でも再現できる指示の出し方を探り、どのレベルで品質が跳ね上がるかを確認します。

VER.01

テキスト仕様書のみ

サービス内容・コピー・構成をテキストで渡す

VER.02

ChatGPT画像を参考添付

ChatGPT生成の参考画像と詳細な変更指示を一緒に送る

VER.03

テキストで細かく指示

フォント変更・レイアウト修正を言葉だけで具体的に伝える

VER.04

参考SSで色を指定

好みのサイトのSSを送り「この色に」と一言で伝える

VER.01

テキスト仕様書をそのまま渡す

のどかさんが書いてくれたサービス概要・コピー・セクション構成を、ほぼそのままClaude Codeに貼り付けて作成。画像も参考サイトも提示なし。

Input — プロンプト
あや → Claude Code
あなたは売れるLPを作るデザイナー兼コピーライターです。 特に「女性をターゲットにしたLP」のデザイン・コピーが得意で、AIっぽい定型句を一切使わずに作ります。 以下の「LP構成案」をもとに、HTMLとCSSでランディングページを作ってください。 構成案の順序・文面はそのまま使ってください。 【コピーのルール】 - 主語は「あなた」、抽象語禁止（「自信がつく」「あなたの可能性を広げる」「理想の○○へ」など中身のない言葉は一切使わない） - AI定型句禁止（「さあ、始めましょう」「いかがでしょうか？」「〜の世界へようこそ」「革新的な」など） - 数字・固有名詞・動詞から始まる文を意識する - 架空のお客様の声や数字（「満足度97%」等）は作らない。プレースホルダーで置く - 女性ターゲットに感情を動かす言葉を使う（プリンセスマーケティング視点） - 機能的価値＋情緒的価値の両方を必ず盛り込む - キャッチコピーは「ターゲット × 悩み × ベネフィット」を内包 【デザインのルール】 - 絵文字一切禁止（チェック等はCSS疑似要素で） - フォント最大3種類。明朝体を長文本文に使わない - 色：アクセント1色のみ。原色そのまま禁止、派手なグラデ禁止 - テキスト#1e1e1e / 補足#6a6a6a / 背景#faf8f5（純白でなく少し色味のある白） - 角丸は8pxか16pxに統一 - シャドウは薄く広く（0 8px 30px rgba(0,0,0,0.05)） - 女性ターゲット向けの柔らかさ・上質感 【フォントサイズ（clamp必須）】 - 本文16px以上、H1 clamp(28px,7vw,48px)、H2 clamp(22px,5vw,32px)、H3 clamp(17px,4vw,22px) - 本文行間1.7〜1.8 / 見出し行間1.3〜1.4 【スマホファースト】 - ブレークポイント768px - 横スクロール禁止、タップ領域44px以上 - 2カラム以上は必ずスマホで縦積み 【余白・レイアウト】 - セクション間：PC 80px / スマホ 48px - 要素間は8の倍数（8/16/24/32px） - 左右パディング最低20px、テキストmax-width: 720px 【ビジュアル】 - 全セクションに画像 or 図解必須。なければpicsum.photosやCSS図解 - 絵文字をアイコン代わりにしない（SVG or CSS疑似要素） - 画像はwidth: 100%; max-width: 100% 【セクションごとの推奨カラム】 - FV: PC2col（左テキスト60%+右画像40%）/ スマホ縦積み - 共感: PC3colカード / スマホ1col - 未来: PC2col(Before/After) / スマホ縦積み - サービス: PC2col×3行 / スマホ1col - 信頼: PC3colカード / スマホ1col 【出力フォーマット】 - HTML 1枚完結、CSSはstyle内、altテキスト必須 --- # LP構成案（のどかさん作成） セクション1｜ファーストビュー キャッチコピー 『なんとなくの私』を卒業する。 "大人のおしゃれ部活"、始動。 サービス名：& me サブコピー 診断を受けたのに、結局いつも同じ服。 「これで合ってる？」を繰り返していた私が、 "私らしい似合う"を楽しみながら選べるようになる場所。 ターゲット ✔ 診断を受けたけど活かしきれていない女性 ✔ 40代になって何を着ればいいかわからなくなった女性 ✔ 無難な服ばかり選んでしまう女性 ✔ 「似合う」と「好き」のバランスに悩んでいる女性 ✔ おしゃれを頑張りたいけど、一人だと続かない女性 ✔ 自分を後回しにしてきたけど、そろそろ自分を整えたい女性 セクション2｜こんなお悩みありませんか？ ✔ 診断を受けた時は納得したのに、結局いつも同じ服に戻ってしまう ✔ お店に行っても「何を買えばいいかわからない」と疲れて帰ってしまう ✔ 「これ似合ってるのかな？」と不安で、無難な服ばかり選んでしまう ✔ トレンドを見ても、自分にどう取り入れたらいいかわからない ✔ 昔はもっとおしゃれを楽しめていたのに、最近は鏡を見るたびにモヤモヤする ✔ 子育てや仕事を優先して、自分のことを後回しにしてきた でも本当は、もっとおしゃれを楽しみたい。 もっと自分を好きになりたい。 セクション3｜Before / After Before: 何を着てもピンとこない / 毎朝「何着よう…」で時間がかかる After: 自分に似合う服を自分で選べるようになる / 鏡を見るたび少し気分が上がる セクション4｜サービス内容（5つ） 01 コーデ提案 / 02 トレンド解説 / 03 メイクアドバイス / 04 おしゃれ相談 / 05 イベント・企画 【参考URL】 - https://lp-fujiba-tomomi.vercel.app/ - https://lp.chic-image.com/p/ZOIzQoKZAohW - https://shelikes.jp/

結果・考察

よかった点
  • 仕様書通りのセクション構成で完成
  • 清潔感のある読みやすいデザイン
  • CTAボタン・フォームの配置が的確
  • コピーテキストがそのまま反映
改善できる点
  • 写真・ビジュアル要素が一切ない
  • デザインがやや無個性・汎用的
  • ブランドらしいムードが出にくい
VER.02

ChatGPT生成の参考画像を添付して変更指示を出す

ChatGPTで作ったファッションLP風の画像をそのまま添付し、「この雰囲気で直して」と具体的な変更点もテキストで一緒に伝えたバージョン。

Input — プロンプト＋画像
あや → Claude Code
こちらのLPに参考画像のテイストを反映してください 今Claudeで作ってもらったLPに、こちらで送付した画像の要素を入れ込んでください。 具体的な修正内容は以下の通りです： 1. ビフォーアフターのセクション (a) 女性の写真やアイコンを追加する (b) 筆記体の装飾、手書きの吹き出し文字を入れる 2. 受講生の声 (a) こちらにも写真を差し込む 3. ファーストビュー (a) 参考画像のように、右側に女性を配置する 全体のデザイン面については、ピンクからオレンジ、黄色への薄いグラデーションを使い、文字はカラーコード #545454 などの黒に近いグレーを使用してください。 海外の雑誌風のような、スタイリッシュでモダンな雰囲気に仕上げたいです。サンセリフ体などの装飾も使って、海外チックでかっこいいLPにしてください。こちらの一番最初のポン出しのものは「ボリューム1」として取っておき、こちらの画像を追加したものを「ボリューム2」として、その過程を見せていきたいです。 ですので、一つ目のURLはいじらずに、こちらをボリューム2としてください。
Output — 完成LP
gokigen-design.github.io/aya-ai-design/and-me-lp-snap-ver2.html
このLPを全画面で見る

結果・考察

よかった点
  • 写真スペース・吹き出しが追加された
  • マガジンらしいレイアウトに進化
  • 筆記体デコで华やかさが出た
  • セクション数・情報量が増えた
改善できる点
  • 色味がまだイメージと違う
  • フォントの雰囲気がポップすぎる
  • セクション間の余白・バランス調整が必要
VER.03

テキストだけで細かく指示する（2回のやりとり）

画像なし。「筆記体に変更して」「このセクションのレイアウトを組み直して」と、言葉だけで具体的な修正を2回に分けて伝えたバージョン。

Input — 2回のプロンプト（テキストのみ）
あや → Claude Code（1回目）
筆記体に変更して
あや → Claude Code（2回目）
こんなお悩みありませんか？のところが変なセクションわけになっているので こんなお悩みありませんか？の下にもっとおしゃれを楽しみたいを下にレイアウトを組み直してください
Output — 完成LP
gokigen-design.github.io/aya-ai-design/and-me-lp-snap-ver3.html
このLPを全画面で見る

結果・考察

よかった点
  • 一言「筆記体に変更して」で見出しフォントが変わった
  • セクションの問題点を具体的に説明したら意図通りに整理された
  • 画像なしでも、言葉が具体的なら意図が伝わる
改善できる点
  • 「筆記体」→後で「明朝体」に言い直しが必要だった（言葉の確認が大事）
  • 色味はまだVer.02のオレンジ系のまま
  • 色指定だけ別で次に送ることになった
VER.04

「好きなサイト」のSSを送って「この色にして」と一言

STORYwebのスクリーンショットを1枚添付して「グレーと黒とピンクの色にして」と一言だけ。これだけでイメージ通りの配色に変わった最終版。

Input — プロンプト＋参考SS
あや → Claude Code
色味はこんな感じのグレーと黒とピンクのからーにしてください
Output — 完成LP
gokigen-design.github.io/aya-ai-design/and-me-lp-v2.html
最終版LPを全画面で見る

結果・考察

よかった点
  • カラーがイメージ通りに仕上がった
  • ブランドの世界観がしっかり表現できた
  • STORYwebのエレガントさを再現
  • 4ステップ中もっとも完成度が高い
ポイント
  • 色名だけでなくカラーコードも伝えると確実
  • 参考SSと言語説明の組み合わせが効果的
  • 「グレー×黒×ピンク」と3色に絞るのがコツ
