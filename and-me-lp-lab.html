& me LP Lab

プロンプトの違いで LP の仕上がりはどう変わる？4ステップ検証レポート

あや ゆみ ちゃかな

検証の目的

同じサービス「& me（ファッションコミュニティ）」のLPを、プロンプトの詳しさを段階的に変えながら4回作成。
初心者でも再現できる指示の出し方を探り、どのレベルで品質が跳ね上がるかを確認します。

VER.01

テキスト仕様書のみ

サービス内容・コピー・構成をテキストで渡す

VER.02

ChatGPT画像を追加

AI生成の参考イメージを組み込む

VER.03

参考サイトのSS共有

実在するサイトのスクリーンショットを見せる

VER.04

色・細部を言語化

カラーコードや具体的な指示を追加

VER.01

テキスト仕様書をそのまま渡す

のどかさんが書いてくれたサービス概要・コピー・セクション構成を、ほぼそのままClaude Codeに貼り付けて作成。画像も参考サイトも提示なし。

Input — プロンプト
あや → Claude Code
以下の内容でLPを作成してください。 【サービス名】& me 【ターゲット】30〜40代のファッションに悩む女性 【コンセプト】おしゃれを一緒に楽しむ仲間のいるコミュニティ 【セクション構成】 1. FV：キャッチコピー＋CTAボタン 2. こんなお悩みありませんか？（6項目） 3. Before / After 4. サービス内容（3プラン） 5. 申し込みCTA 【デザイン指定】 - フォント：丸ゴシック - アクセントカラー：ピンク系 - 絵文字禁止・本文14px以上
Output — 完成LP
gokigen-design.github.io/aya-ai-design/and-me-lp.html
このLPを全画面で見る

結果・考察

よかった点
  • 仕様書通りのセクション構成で完成
  • 清潔感のある読みやすいデザイン
  • CTAボタン・フォームの配置が的確
  • コピーテキストがそのまま反映
改善できる点
  • 写真・ビジュアル要素が一切ない
  • デザインがやや無個性・汎用的
  • ブランドらしいムードが出にくい
VER.02

ChatGPT で作ったイメージ画像を渡す

ChatGPTでファッション系のイメージ画像を生成し、スクリーンショットをClaude Codeに添付。「こういうムードで」と伝えたバージョン。

Input — プロンプト＋画像
あや → Claude Code

ChatGPTで生成したイメージ画像をここに追加してください
（GitHubの画像URLか、imgタグで差し替え）

この画像のようなムードで、Ver.01をリニューアルしてください。 追加してほしいこと： ・BAセクションに「Before→After」の女性写真を追加 ・筆記体の装飾テキスト（"for you" など） ・吹き出し風のコメントデザイン ・お客様の声セクションを追加（顔写真＋テキスト） ・FVの右側に女性の写真スペース ・マガジン風のレイアウトにしてほしい
Output — 完成LP
gokigen-design.github.io/aya-ai-design/and-me-lp-snap-ver2.html
このLPを全画面で見る

結果・考察

よかった点
  • 写真スペース・吹き出しが追加された
  • マガジンらしいレイアウトに進化
  • 筆記体デコで华やかさが出た
  • セクション数・情報量が増えた
改善できる点
  • 色味がまだイメージと違う
  • フォントの雰囲気がポップすぎる
  • セクション間の余白・バランス調整が必要
VER.03

参考サイトのスクリーンショットを送る

実際に「いいな」と思ったファッション系LPのスクリーンショットを添付。「このサイトみたいにして」と伝えたバージョン。フォントも明朝体に変更、レイアウトも組み直し。

Input — プロンプト＋スクリーンショット
あや → Claude Code

参考にしたサイトのスクリーンショットをここに追加してください

このサイトのスタイルを参考に修正してほしいです。 ・見出しフォントを明朝体（Shippori Mincho）に変更 ・「こんなお悩みありませんか？」のセクションの 　レイアウトを組み直してほしい 　→ 問題リストを上、「もっとおしゃれを楽しみたい」 　　 という締めの文章を下に移動して
Output — 完成LP
gokigen-design.github.io/aya-ai-design/and-me-lp-snap-ver3.html
このLPを全画面で見る

結果・考察

よかった点
  • 明朝体でエレガントな雰囲気に
  • セクション構造が読みやすく整理された
  • 参考サイトのムードが伝わった
改善できる点
  • 色味がまだ合っていない（オレンジ系が残る）
  • もう少し具体的な色指定が必要
VER.04

色・雰囲気を具体的に言語化して指示する

STORYwebのスクリーンショットを添付し、「グレー・ブラック・ホットピンク」と色を言語で明確に指定。もっとも精度の高い仕上がりになったバージョン。

Input — プロンプト＋参考SS
あや → Claude Code

STORYwebのスクリーンショットをここに追加してください

色味はこんな感じのグレーと黒とピンクの カラーにしてください。 具体的には： ・背景：ライトグレー（#f8f8f8） ・テキスト：ほぼ黒（#1a1a1a） ・アクセント：ホットピンク（#D4006E） ・グラデーションもピンク系に統一
Output — 完成LP
gokigen-design.github.io/aya-ai-design/and-me-lp-v2.html
最終版LPを全画面で見る

結果・考察

よかった点
  • カラーがイメージ通りに仕上がった
  • ブランドの世界観がしっかり表現できた
  • STORYwebのエレガントさを再現
  • 4ステップ中もっとも完成度が高い
ポイント
  • 色名だけでなくカラーコードも伝えると確実
  • 参考SSと言語説明の組み合わせが効果的
  • 「グレー×黒×ピンク」と3色に絞るのがコツ
