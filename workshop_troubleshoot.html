5人のつまずきと解決方法

画面のエラーメッセージをもとに、原因と対処法を一人ずつ解説します。

前

まほさん・なつえさん・和田あゆみさん

3名共通のつまずき（Mac）

前段階で停止

画面に出たエラー

zsh: command not found: claude

原因

パソコン自体に「Claude Code」がインストールされていません。
SuperpowersもUI/UX Pro Maxも、インストール作業にすら入れていない状態です。

和田さんの場合：インストール途中に「このフォルダを信頼しますか？」という確認が何度も出てきて止まってしまった可能性が高いです。確認はすべて「はい / Yes / Enter」で進めて大丈夫です。

解決手順（ターミナルに1行ずつ実行）

1

Node.js（動かすための土台）が入っているか確認

node --version

「v18.○○」などの数字が出ればOK。
「command not found」が出た場合は nodejs.org からLTS版をインストールしてください。

2

Claude Code をインストール

npm install -g @anthropic-ai/claude-code

途中で「Y/N」「Yes/No」が出たら Y または Yes を選んでください。

3

起動確認

claude

虫マークが出たら成功です。

中

はらのどかさん

UI/UX Pro Max の導入中（Mac）

作業途中

画面に出たメッセージ

外部のGitHubリポジトリからスキルをダウンロード・導入することはできません
あなたの入力: ://github.

原因（2つあります）

原因1：黒いターミナル画面のClaude Codeではなく、ブラウザ（ChromeやSafari）で開く普通の「Claude.ai」のチャット欄にURLを貼ってしまいました。

原因2：URLが途中から貼られていて「https」が欠けた状態（://github.）になっています。

ブラウザのClaude.aiではスキルのインストールはできません。ターミナルのClaude Codeで行う必要があります。

解決手順

1

ターミナルを開いて claude と打ってEnter（虫マークを出す）

2

虫マークが出たら、入力欄に以下をそのまま貼り付けてEnter

https://github.com/nextlevelbuilder/ui-ux-pro-max-skill.git このスキルを導入してください
3

「実行してよいですか？」と出たら、入力欄に打つ：

実行しても良い
覚えておいてほしいこと：
ブラウザのClaude.ai = 普通の会話だけ
ターミナルのClaude Code = スキルのインストール・ファイル作成もできる

Windowsの方専用

Windows でよく出るエラーと解決方法

Macと異なる手順が必要な場合があります。

よく出るエラー

このシステムではスクリプトの実行が無効になっているため… PSSecurityException / UnauthorizedAccess

原因

Windows のセキュリティ設定がスクリプトの実行をブロックしています。

解決手順

1

Windowsキーを押して「PowerShell」と検索
「Windows PowerShell」を右クリック → 管理者として実行

2

以下をコピペしてEnter：

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
3

「Y はい」と聞かれたら Y を打ってEnter

4

通常のターミナルで claude を実行

ログイン（認証）がうまくいかないとき：
「Browser didn't open?」と出たら → c キーでURLをコピー → ブラウザに貼り付けてログイン → コードをコピー → ターミナルに右クリックで貼り付けてEnter

コードには時間制限があります。URLが出たらすぐ進めてください。失敗したら「Press Enter to retry」でやり直せます。
