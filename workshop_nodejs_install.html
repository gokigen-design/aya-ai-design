Claude Code セットアップサポート

Node.js から Claude Code まで
完全インストール手順

原因がわかったので、ここから一気にいきましょう

なぜインストールできなかったのか？

Claude Code を入れようとしていましたが、「Node.js」というClaude Codeを動かす土台のソフトが入っていない状態でした。

家を建てたい！と思って 木材（Claude Code） を買ったけど、そもそも 土地（Node.js） がなかった、という状態です。
土地さえ用意できれば、その上に家が建てられます！

必要だったもの
Node.js（土台）
入れたいもの
Claude Code（建物）

よくある質問への答え

「アンインストールしてからやるの？」
→ いいえ！何もアンインストールしなくて大丈夫です。
　 Node.js を新しく入れるだけで解決します。

1

STEP 1

Node.js をインストール

土台を用意します

1
下記のダウンロード専用ページをブラウザで開く
nodejs.org/ja/download を開く →
2
画面が開いたら、中央にある深緑色の「macOSインストーラー (.pkg)」ボタンをクリック
※他の場所や英語・数字のテキストはクリックしなくてOK
↑ 「macOS インストーラー (.pkg)」の緑のボタンをクリック
3
ダウンロードフォルダを開いて、ダウンロードしたファイル（node-v24.16.0.pkg など）をダブルクリックして開く
※Finderの左サイドバーの「ダウンロード」フォルダ、またはDockのダウンロードアイコンから
4
「Node.jsのインストール」画面（ようこそ画面）が開く。右下の「続ける」を押す
↑ この画面が出たら右下の「続ける」を押す
5
次は「使用許諾契約」画面が出るので、右下の「続ける」を押す
↑ 右下の「続ける」を押す
6
小窓が出てきます。「同意する」（青いボタン）を押す
↑ 右側の青い「同意する」を押す
7
「Macintosh HDに標準インストール」画面が出るので、右下の「インストール」を押す
↑ 右下の青い「インストール」を押す
8
パスワード入力の小窓が出るので、Macのログインパスワードを入力して「ソフトウェアをインストール」を押す
※いつもMacを起動するときのパスワード。Touch IDの方は指紋認証でもOK
↑ パスワードを入力したら青い「ソフトウェアをインストール」を押す

⑤〜⑧ の流れをまとめると

右下のボタンを順番に押していくだけ：
続ける → 同意する → インストール → パスワード入力

9
「インストールが完了しました」と出たら成功！
右下の「閉じる」を押す
↑ 「インストールが完了しました」が出たら右下の「閉じる」を押す
10
「インストーラをゴミ箱に入れますか？」が出てきます。
「ゴミ箱に入れる」を押してOK（インストール完了後はもう不要なので捨てて大丈夫です）
↑ 「ゴミ箱に入れる」を押してOK
11
【ここが一番大事！】
必須

インストールが完全に完了したら、
今開いている黒い画面（ターミナル）を
一度完全に閉じて、新しく開き直してください。

※開き直さないと、パソコンが新しい土地（Node.js）を認識してくれません！

STEP 1 完了チェック

  • Node.js のインストーラーで「インストール完了」が表示された
  • ターミナルを一度閉じて、新しく開き直した
2

STEP 2

Node.js が入ったか確認

土地が用意できたかチェック

1
新しく開いたターミナルに、下記をコピペしてEnter
ターミナル
% node --version
2
下記のような「v24.16.0」などの数字が表示されればOK！
% node --version
v24.16.0 ← 数字が出れば成功！

「command not found」と出た場合

Node.jsのインストールが完了していないか、ターミナルを開き直していない可能性があります。
STEP 1 の「ターミナルを開き直す」をもう一度確認してください。

STEP 2 完了チェック

  • 「v○○.○○.○○」など数字のバージョンが表示された
3

STEP 3

Claude Code をインストール

土地ができたので、いよいよ木材を組み立てます

1
下記をコピペしてターミナルに貼り付け、Enterを押す
ターミナル
% npm install -g @anthropic-ai/claude-code
2
数分待ちます。画面がダダダッと動き、最後に「added 247 packages」などの文字が出たら完了！

「Permission denied」というエラーが出たら

頭に sudo をつけて、下記のように打ち直してください。

% sudo npm install -g @anthropic-ai/claude-code

Macのパスワードを求められるので、入力してEnterを押せば進みます。

STEP 3 完了チェック

  • 「added ○○ packages」と表示された
  • 赤いエラーが出ていない（または sudo で再実行してエラーが消えた）
4

STEP 4

起動！

最後の起動確認です

1
下記を打ってEnter
ターミナル
% claude
2
画面に虫（アリ）のマークが出たら大成功！🎉

虫マークが出た後の流れ

「ログイン方法を選んでください」と聞かれたら、1番（Claude account with subscription）が選ばれた状態で Enter を押してください。
その後ブラウザが開いて、Claudeアカウントでログインすれば完了です！
